# Doc Co-Authoring

Structured workflow for collaborative document creation. Three stages: gather context → build section by section → test with fresh eyes.

## Stage 1: Context Gathering

Before writing anything, collect:
- Document type (proposal, spec, report, memo, strategy doc, etc.)
- Target audience (who reads this, what do they already know?)
- Desired impact (what should the reader think/feel/do after reading?)
- Key constraints (length, format, tone, deadline)
- Background material (existing docs, data, prior work)

Ask clarifying questions. Never start writing until you understand the purpose.

## Stage 2: Refinement and Structure

Build the document section by section using a five-step loop per section:

1. **Clarify** — ask any remaining questions for this section
2. **Brainstorm** — generate structural options or key points
3. **Curate** — narrow to the strongest approach
4. **Gap check** — identify missing context or evidence
5. **Draft** — write the section

**Important**: Use targeted edits to make changes — never reprint the whole document. This keeps context focused and iteration fast.

Continue section by section until the full document is drafted.

## Stage 3: Reader Testing

Validate the document with a fresh-context perspective:

1. Read as if you've never seen the background material
2. Identify questions a reader would have that the document doesn't answer
3. Check that the document works for someone unfamiliar with the authoring process
4. Propose specific fixes for identified gaps

## Principles

- **User agency**: The author makes decisions — offer options, don't impose
- **Quality over speed**: Take time to get sections right before moving on
- **Iterative refinement**: Return to earlier sections when new context changes them
- **Test with fresh eyes**: Writing that made sense during drafting often breaks on re-read
