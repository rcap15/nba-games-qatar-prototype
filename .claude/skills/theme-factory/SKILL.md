# Theme Factory

Applies cohesive color and typography themes to presentations, documents, and web artifacts.

## Available Themes

1. **Ocean Depths** — Deep teals, navy blues, aquatic palette
2. **Sunset Boulevard** — Warm oranges, corals, golden tones
3. **Forest Canopy** — Earthy greens, warm browns, organic palette
4. **Modern Minimalist** — Clean neutrals, precise typography, maximum whitespace
5. **Golden Hour** — Rich ambers, soft golds, warm neutrals
6. **Arctic Frost** — Cool grays, icy blues, crisp whites
7. **Desert Rose** — Dusty pinks, terracotta, sand tones
8. **Tech Innovation** — Electric blues, sharp contrasts, modern sans-serif
9. **Botanical Garden** — Fresh greens, floral accents, natural warmth
10. **Midnight Galaxy** — Deep purples, star-point highlights, dark luxury

## Usage Process

1. Display the theme showcase to the user
2. Request their theme preference
3. Get explicit confirmation of the selected theme
4. Apply the theme's colors and fonts throughout the artifact

## Custom Themes

When none of the pre-set themes fit the project:
1. User describes their vision or provides reference colors/mood
2. Generate a new theme: name, palette (5–7 colors), font pairing
3. Review with user
4. Apply to the artifact

## Application Standards

- Apply colors and fonts consistently across all elements
- Ensure text maintains WCAG AA contrast on all backgrounds
- Use semantic color roles: primary, surface, accent, text, border
- Maintain visual coherence — all elements serve the same theme
- Do not mix themes within the same artifact
